몽실이 시행착오 기록

기억 아카이브를 만들며 막혔던 것과 풀어낸 방법. 새로 생기면 아래에 덧붙인다.

기억할 것

  • AI 말투의 한계는 모델 크기 문제다. 지금은 gemma3:4b(노트북 CPU)라 한국어 활용이 약해서, 버튼 말을 목록에서 고르게 막아 두었다. 더 큰 모델(gemma3:12b 등)이나 클라우드 AI(Gemini, Claude)로 바꾸면 질문·버튼이 자연스러워지고 목록을 풀 수 있다.
  • 사람·그날의 일 단계(L3·L4)는 아직 AI가 자유롭게 만든다. 여기서 어색한 말이 남아 있다.
  • 이야기책 문장에 AI가 살짝 덧붙이는 일이 아직 있다 (예: "갈치가 많이 팔렸다").
  • 터널 주소는 켤 때마다 바뀐다. 배포 사이트에서 AI를 쓰려면 Vercel OLLAMA_URL을 갱신하고 다시 배포해야 한다. 고정 터널은 보류했다 (아래 기록).

기록

고정 터널을 만들려다 보류 배포

2026-11-03
문제
빠른 터널은 켤 때마다 주소가 바뀌어 Vercel 값을 매번 고쳐야 한다.
원인
ngrok 고정 주소를 쓰려 했지만, 지금 네트워크가 ngrok.com과 다운로드 서버를 막았다 (연결 끊김). tailscale.com도 열리지 않았다. Cloudflare는 된다.
한 일
당분간 매번 주소를 바꾸기로 했다. 나중 선택지: Cloudflare 이름 있는 터널(도메인 필요) 또는 Vercel CLI로 주소 갱신 자동화. 시연 장소 네트워크도 미리 확인할 것.

몽실이가 틀린 한국어를 말함 AI

2026-11-03
문제
"채소랑", "나 동네" 같은 낱말 버튼, "붉었요", "즐거우셨었군요" 같은 틀린 어미.
원인
작은 모델이 자료 낱말을 그대로 베끼고, 한국어 활용을 자주 틀린다.
한 일
① 규칙 검사: 버튼은 "~요" 문장만, 겹친 과거형 고치기, 받아 주는 말은 규칙으로("시끄러웠어요" → "시끄러웠군요"). ② 감각·느낌·의미 단계 버튼은 미리 적은 목록(src/lib/answers.js)에서만 고르게 하고, JSON 형식의 enum으로 목록 밖의 말은 못 쓰게 했다.

원인
